5 · PWM

①Worum geht es?

Bisher war die LED nur an oder aus. Mit PWM wird sie stufenlos heller oder dunkler. Dafür schreibst du statt 0 oder 1 eine Zahl von 0 bis 255 auf einen Ausgang: b.do0 = 128 ist halbe Helligkeit.

②Board

Die eingebaute LED kann nur an/aus. Für PWM nimm eine eigene LED an Ausgang D0 (GPIO5) – LED mit Vorwiderstand (z. B. 220 Ω) von D0 nach GND. Mit „Make" bekommt dieser Pin den Namen lampe.

③Code

Die LED wird langsam heller und wieder dunkler (Atmen):

h = 0
schritt = 5
while True:
    b.do0 = h
    h = h + schritt
    if h >= 255 or h <= 0:
        schritt = -schritt
    wait(20)

Hinweis: b.do0 ist derselbe Pin wie lampe (D0/GPIO5).

④Experimentiere

Mach schritt größer (z. B. 15) für schnelleres Atmen, oder setze einen festen Wert wie b.do0 = 40 für dauerhaft gedimmt.

h = 0
schritt = 15
while True:
    b.do0 = h
    h = h + schritt
    if h >= 255 or h <= 0:
        schritt = -schritt
    wait(20)
