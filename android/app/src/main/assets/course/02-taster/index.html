2 · BOOT-Taste

①Worum geht es?

Auf dem Board ist eine kleine Taste mit der Aufschrift BOOT. Im Programm heißt sie b1. Damit lernt der ESP32, auf einen Tastendruck zu reagieren – das ist ein digitaler Eingang: gedrückt oder nicht.

②Board

Nichts zu verkabeln: die BOOT-Taste (b1) und die LED (led) sind schon auf dem Board.

③Code

Die LED leuchtet, solange du die BOOT-Taste gedrückt hältst:

while True:
    led.v = b1
    wait(20)

④Experimentiere: Umschalten

Jetzt soll ein Druck die LED umschalten (an → aus → an). Dafür merkt sich das Programm den vorherigen Zustand:

zustand = 0
vorher = 0
while True:
    jetzt = 1 if b1 else 0
    if jetzt and not vorher:
        zustand = 1 - zustand
        led.v = zustand
    vorher = jetzt
    wait(20)
