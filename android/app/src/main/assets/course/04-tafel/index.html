4 · Tafel

①Worum geht es?

Reiner Text im Terminal ist praktisch zum Debuggen. Schöner wird es mit der Tafel: Schreibst du log("NAME:wert"), zeigt ein Widget den Wert als Zeiger, Balken oder Lämpchen an. So wird dein Handy zur Anzeige.

②Code

Dieses Programm blinkt und schickt zusätzlich eine „Temperatur" an die Tafel:

n = 0
while True:
    led.v = 1
    log("LED:1")
    log("TEMP:" + str(20 + n % 15))
    wait(500)
    led.v = 0
    log("LED:0")
    wait(500)
    n = n + 1

③Anschauen

Im Terminal auf Tafel umschalten. Ein neues Projekt hat schon Widgets für TEMP und LED. Fehlt eines, lege es mit + Widget an (Name genau TEMP bzw. LED).

④Experimentiere

Ändere die Formel 20 + n % 15, damit der Zeiger anders ausschlägt. Oder sende einen zweiten Wert, z. B. log("DIST:" + str(n % 100)).
