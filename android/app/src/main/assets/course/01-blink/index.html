1 · ESP32 & LED

①Worum geht es?

Auf dem ESP32 ist schon eine LED eingebaut. Sie heißt im Programm led. Wir lassen sie blinken: an, warten, aus, warten – immer wieder.

②Board

Für die eingebaute LED musst du nichts verkabeln und nichts einstellen – led ist schon da.

③Code

So blinkt die LED jede halbe Sekunde:

while True:
    led.v = 1
    wait(500)
    led.v = 0
    wait(500)

Danach „Start" (▶) drücken, um das Programm auf den ESP32 zu übertragen. Die LED blinkt.

④Experimentiere

Ändere beide wait(500) auf wait(100) – die LED blinkt viel schneller. Probiere auch wait(1000).
