3 · Logging

①Worum geht es?

Mit log(...) schickt das Programm Text und Zahlen zurück ans Handy. So siehst du, was der ESP32 gerade macht – perfekt, um Fehler zu finden und ein Programm zu verstehen.

②Code

Dieses Programm zählt hoch und schickt den Zählerstand jede Sekunde:

n = 0
while True:
    log("Zähler:", n)
    n = n + 1
    wait(1000)

③Anschauen

Nach „Start" (▶) die Ausgabe im Terminal ansehen – dort läuft der Zähler.

④Experimentiere

Ändere den Text in log("Zähler:", n), oder logge etwas Eigenes dazu, z. B. log("doppelt:", n * 2).
